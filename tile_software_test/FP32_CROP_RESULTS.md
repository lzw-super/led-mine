# FP32 小 tile / crop 实测结果

日期：2026-11-18。9 组组合，完整 93 对 SID Sony 验证图像（100×:29、250×:29、300×:35），每幅 packed 输入 4×1424×2128。没有裁掉原图边缘。

## 配置与计时口径

- 权重：`experiments/LED_Pretrain_CVPR20_ELD_LearningDWT_Haar_L3_RepNCB_W32_ReLU_LLStemNoAct/models/net_g_255000.pth`；SHA256 `2d1bbbb6775b7466a9466d20e32d446f6f4ce9e414c31fc3ca7fc04a0125acdc`。
- GPU：NVIDIA GeForce RTX 4090；PyTorch 1.13.1+cu117；CUDA 11.7；cuDNN 8500。
- 同一份 RepNCB 部署融合模型用于整图与 tile；参数/激活 FP32，AMP、TF32 均关闭，eval/inference_mode；cuDNN deterministic=True、benchmark=False。
- T 是含 halo 的输入窗口最大尺寸，单边 h，core/步长 C=T−2h。crop 丢弃内部 halo，只复制 core；真实图像边缘裁短输入、由网络自行处理 padding。
- 当前三个 T 均小于 2×56=112，无法在这些输入窗口内同时容纳理论 halo=56 与正面积 core；本次测试是允许精度损失的近似分块方案，而不是严格等价分块。
- halo=10 保持用户指定值，不向 8 对齐：窗口起点相位变化，且部分边界块有内部补齐，其损失包含上下文不足与 Haar/S2D 相位变化，不能解释为单纯 halo 大小效应。h=8/16 的起点与 core 均为 8 倍数，但仍远小于理论 56。
- 全集精度与 GPU 批处理计时使用最多 64 个同形状 tile 一批；边缘按实际 shape 分组，不将边缘补成最大 T。所有输入输出在 GPU；同步 wall time 包含切片、组 batch、前向和 crop 写回，排除文件读取、CPU→GPU、指标及照度校正。每 ratio 首图预热全部配置，逐图随机配置顺序。
- 串行计时另选每个 ratio 的第一幅完整图（共 3 幅），每配置预热一次、计时三次，表中为 9 次测量的中位数。不是全集串行平均，也不是 FPGA 时延。并验证这三图每个配置串行/批量输出 allclose（rtol=1e-4,atol=2e-6）。
- 精度：RAW 4 通道；沿用实验全图 illumination correction（拼接后执行，使用 GT 拟合单个标量）与 crop_border=2；PSNR 使用 double MSE 的标准 10log10(1/MSE)，SSIM 用仓库 numpy 实现。PSNR 未加仓库 tensor 指标的 1e-8 epsilon，故绝对值不应与训练日志直接逐位比较。另提供未校正 PSNR 损失，避免全图亮度拟合掩盖变化。
- “损失”=整图−tile，正数表示精度降低，负数表示该项略有提升。对每幅图指标取算术平均，全体按 93 图加权，不先将三个 ratio 等权平均。相对整图误差在未经校正、未裁边的原始输出上计算。

## 结果解读

- 平均精度优先：**96/16**，PSNR 平均损失 0.0937 dB。该配置单图损失中位数 0.0583 dB，最大损失 **0.5112 dB**，发生于 300×、`10217_00_0.033s.ARW.npz`；平均值不能替代最坏情况约束。
- GPU 批量时间最短：**96/10**，平均 35.95 ms。但 halo=10 的相位不对齐使其不适合作为严格对齐硬件实现的基准，且其 GPU 性能优势不能外推到 FPGA。
- 若要求相位对齐并优先串行软件时间，选择 96/8；若优先精度，选择 96/16。此结论仅限当前九个候选、当前模型与验证集。
- 所有九组在此次 GPU 实测中都慢于整图推理。没有任何一组满足理论严格等价条件；是否接受上述损失，应按应用的平均和最坏图像质量预算决定。
