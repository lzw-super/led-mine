单张特征表按最大 T×T 计算，实际边缘 tile 可更小；两张特征 ping-pong 容量为最后一列的 2 倍。FP32 容量为表中 2 倍，INT8 为一半（不含更宽累加器）。

推荐起点：512/64/384；最小精确 halo 候选：512/56/400；小内存候选：256/56/144 与 256/64/128。应结合片上缓存寿命分析，而非只看输入容量。

对照：在选定 T 下测试 h=0/32/48（不足 halo）与 h=80（冗余）；它们用于确定误差和冗余成本，不改变 h=56 的结构下界。

原图边界按 README 截断；这里没有裁掉任何输出像素，也没有额外补大整幅图。FPGA 如对所有末块都做完整 T×T 运算，工作量应改为 tile_count×T²/(H×W)，并另行证明有效边界语义。
