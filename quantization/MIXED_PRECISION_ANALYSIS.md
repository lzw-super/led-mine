# opt1 基础上的混合激活精度分析

## 已有证据

完整指标见 [activation_bits_summary.md](runs/activation_bits_summary.md)。以下均为 93 对图像的 LED 校正 RAW 指标。

|模型|FP32 PSNR / SSIM|W8A8 opt1|W8A16 opt1|A16 − FP32 PSNR / SSIM|
|---|---|---|---|---|
|PReLU|38.272141 / 0.93165700|37.022260 / 0.90662998|38.309332 / 0.93119621|+0.037191 / −0.00046079|
|ReLU|38.049337 / 0.93055644|36.850287 / 0.90563387|38.141375 / 0.93051252|+0.092038 / −0.00004392|

A16 相对 A8 分别恢复约 1.287、1.291 dB，支持激活量化是当前精度损失的重要来源；没有逐层实验，不能据此定位是哪一个激活。
A16 的总体 PSNR 更高，但总体 SSIM 略低，两个模型 300 倍 PSNR 也略低于 FP32。
A16 模型经历额外 QAT 和输出蒸馏；原始 FP32 没有匹配的额外训练，不能把 PSNR 提升直接归因于量化正则化。
建议增加同数据、同 20k 步预算、同教师和损失的 FP32 微调组，以分离训练收益和量化误差。单种子的小幅增益也不代表稳定提升。

## 哪些激活可以先尝试低精度

下表是基于网络数据通路的候选优先级，不是已测得的敏感度排名；目前不能保证任何一层降为 A8 后无损。
所有学习卷积权重仍为 W8，只混合激活位宽，保持 opt1，不同时引入 opt2 或 unsigned 编码。

|激活组（FX 名称）|首轮候选位宽|理由与限制|
|---|---|---|
|Refiner 中间特征 `blocks_0_activation` 到 `blocks_3_activation`|优先逐个测试 A8|这些是学习得到的隐特征，后面仍有卷积可适应误差；空间分辨率为 H/2×W/2、32 通道，降低存储/带宽更值得优先评估。不是断言其不敏感。|
|Refiner `stem`、`blocks_4_activation`|第二批测试 A8|stem 误差影响后续整个主干，最后一个 block 已接近重建 head；分别测试后再合并。|
|LL 子网 `ll_layers_1`、`ll_layers_2_activation` 到 `ll_layers_4_activation`|可尝试 A8|属于隐特征，但处理整体亮度与低频；位于 H/8×W/8，节省的缓冲相对小，若精度敏感不必强降。|
|HF CNN `hf_blocks_0_activation` 到 `hf_blocks_2_activation`|后续谨慎测试 A8，失败可试 A12|是直接加入高频子带的修正量；误差可表现为纹理/细节损失，不能因均值小或数值正负对称就视为安全。|
|输入 `raw` 及 noisy skip 的 S2D `conv2d_4`|优先保留 A16|输入噪声离群值与弱信号共存，输入信息丢失不可由后续变换恢复；S2D 必须继承输入编码。|
|Haar 分析 `conv2d*`、LL/HF `getitem*`、HF residual `add*`|优先保留 A16|opt1 的整带统一量化仍可能受 LL/HF 动态范围差异影响；高频细节和低频亮度直接进入重建。|
|LL 输出 `ll_layers_5`、`cat`、`ll_fusion`|优先保留 A16|进入低频重建和跨层逆 Haar，避免直接损坏重建值。|
|逆 Haar `cat_1..3`、`conv_transpose2d.._2`|优先保留 A16|它们传输重建图像/子带；若降位需要作为接口组评估。|
|Refiner `head`、`cat_4`、`fusion` 与最终 D2S|优先保留 A16|直接生成输出，并与 noisy skip 融合；末端输出量化误差没有后续恢复机会。|

其中 `conv2d_3` 为 preliminary 的 S2D，并非 Haar 分析：保持与 `conv_transpose2d_2` 同尺度/位宽；最终 `conv_transpose2d_3` 为 D2S，保持与 `fusion` 一致。

一个值得验证的起点：**输入、Haar、skip 和重建头为 A16，refiner 隐特征为 A8**。
不要一开始把所有隐特征同时降位；先测 block 0–3，再尝试 stem、block 4 和 LL 隐特征。A12 是 A8 不够精细时的候选折中，不是本轮脚本已经支持的配置。

## 如何验证，而不是凭结构猜测

1. 从完成训练的 W8A16 opt1 checkpoint 做固定权重的敏感度诊断。每次仅把一个激活边界/必须绑定的别名组降为 A8，其余保持 A16。保留相同截断范围：`s8 = s16 × 32767/127`，不要只改 clamp 范围而沿用 A16 步长。
2. 在独立验证场景上记录最终输出 PSNR/SSIM 下降、各倍率变化、局部误差与饱和率。局部 SQNR 只能辅助，输出误差才反映对任务的影响。降低位宽后的卷积输入尺度变化，也必须重新编码对应 INT32 bias。
3. 根据精度损失和实际资源收益选择候选，再做组合测试。单层均可接受不代表组合后仍可接受，误差可能累积或互相影响。
4. 对选中的混合配置执行 QAT，再与训练预算匹配的 A16 组比较。若从已有 A16 模型继续微调，A16 对照也需要同样额外步数，不能直接和原 20k 结果混比。
5. 保留最终 93 对测试集做最终报告，不以反复查看测试结果来挑配置。若从曾用于 QAT 的训练场景划出诊断子集，需要标注其已被训练见过；严格配置选择应在新训练前划分场景并对所有对照统一排除。

可暂以相对 A16 验证 PSNR 下降 ≤0.05 dB 作为探索目标，且同时约束 SSIM 和最差倍率；这只是建议阈值，不是已达到的结果。

HAWQ-V2 提供了基于敏感度的混合权重/激活精度分配方法；对本网络的 38 个边界，可先用逐边界实测退化来获得可解释的筛选依据，而不必先实现 Hessian 估计。
来源：[HAWQ-V2 原论文](https://arxiv.org/abs/1911.03852)。

## FPGA 与实现约束

- S2D/D2S 为纯重排，应沿用来源的尺度和位宽，不应重新增加已在 opt1 中移除的量化边界。
- Conv+activation 作为融合算子，只在激活输出量化；A8/A16 描述存储接口，不代表累加器也使用 8/16 位。
- 混合输入进入 add/concat 需明确尺度和位宽转换。当前 cat 使用统一的输出量化；不能仅把两个不同尺度的整数直接拼起来当成同一编码。
- 只有降低某卷积的输入激活位宽，才使该卷积成为 W8A8 乘法；仅把卷积输出存成 A8，并不会把当前卷积从 W8A16 变成 W8A8。
- 降位的特征存储由 16 位变成 8 位，理论元素存储量减半；整网 BRAM、DSP、带宽收益需按缓冲生命周期、端口位宽和实际算子映射测量，不能直接声称整个 FPGA 资源减半。
- Refiner 隐特征比 LL3 隐特征有更大的空间尺寸，所以通常更有存储优化价值；计算收益也取决于被降位张量的消费者。
- 保留 PReLU α 的 FP32 例外；当前模型仍是 Q/DQ 仿真，真实部署需另行确定 α 定点格式、重定标乘数/移位及累加器范围。

本次仅补充对照与混合精度分析，未修改训练后的模型，未运行逐层敏感度实验。当前训练脚本仍只支持整网 A8 或 A16，不能用现有 `--activation-bits` 参数表达上述逐层混合配置。
